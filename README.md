# Android T5

Repositorio correspondiente a la quinta parte del trabajo de desarrollo de aplicaciones Android.

En esta etapa se desarrollan diferentes ejercicios prácticos utilizando **Kotlin, Android Studio y Jetpack Compose**, trabajando principalmente con listas, cuadrículas, iconos, Material Design, temas y animaciones.

## Contenido

### Ruta 1 - Listas y Cuadrículas

En esta ruta se trabajan diferentes formas de organizar y mostrar información dentro de una interfaz Android.

* **01 - Lista Desplazable: Affirmations**

  * Creación de una lista desplazable.
  * Uso de componentes de listas en Jetpack Compose.
  * Presentación de elementos mediante tarjetas.
  * Manejo de contenido dinámico.

* **03 - Práctica: Cuadrícula**

  * Creación de interfaces utilizando cuadrículas.
  * Organización de elementos en filas y columnas.
  * Uso de componentes de Compose para mostrar colecciones de datos.

* **2 - Icono de la App**

  * Personalización del icono de la aplicación.
  * Configuración de recursos gráficos del proyecto.
  * Aplicación de recursos visuales en Android.

### Ruta 2 - Material Design

Esta ruta está enfocada en el diseño visual de las aplicaciones utilizando los componentes y principios de Material Design.

* **01 - Temas Material Compose**

  * Aplicación de temas en Jetpack Compose.
  * Personalización de colores y tipografías.
  * Uso de Material Design para mejorar la interfaz.
  * Organización de los recursos visuales de la aplicación.

* **02 - Animaciones Compose**

  * Introducción a las animaciones en Jetpack Compose.
  * Creación de transiciones y cambios visuales.
  * Aplicación de animaciones para mejorar la experiencia del usuario.

## Tecnologías utilizadas

* **Kotlin**
* **Android Studio**
* **Jetpack Compose**
* **Material Design**
* **Material 3**

## Objetivo

Aplicar los conceptos de **listas, cuadrículas, recursos gráficos, Material Design y animaciones** en aplicaciones Android desarrolladas con Kotlin y Jetpack Compose.

El objetivo es mejorar progresivamente la construcción de interfaces modernas, organizadas e interactivas, utilizando las herramientas proporcionadas por el ecosistema Android.
